## **🚀 Quick Start Commands**

```bash
# Install
npm install express cors dotenv @google/generative-ai axios firebase
npx expo install expo-av expo-notifications expo-localization expo-linking

# Configure
echo "GEMINI_API_KEY=YOUR_KEY" > .env

# Run (Terminal 1)
node api.js

# Run (Terminal 2)
npx expo start
# Press 'w'

# Test (Terminal 3)
node test-api.js
```
