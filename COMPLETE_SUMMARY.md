## **🚀 Quick Start (Right Now!)**

### **Step 1: Install Dependencies** (2 minutes)
```bash
npm install express cors dotenv @google/generative-ai axios firebase
npx expo install expo-av expo-notifications expo-localization expo-linking
npm install --save-dev nodemon
```

### **Step 2: Add Your API Key** (1 minute)
```bash
# Get key from: https://aistudio.google.com/app/apikey
echo "GEMINI_API_KEY=YOUR_KEY_HERE" > .env
echo "PORT=3000" >> .env
```

### **Step 3: Start API Server** (Terminal 1)
```bash
node api.js
```

### **Step 4: Start Expo App** (Terminal 2)
```bash
npx expo start
# Press 'w' for web browser
```

### **Step 5: Login & Test**
- Email: `learner@example.com`
- Password: anything
- Click Login
- See Kannada Dashboard ✅

## **🐛 Troubleshooting**

### **API Won't Start**
```bash
lsof -i :3000
kill -9 <PID>
node api.js
```

### **Gemini API Error**
- Get new key: https://aistudio.google.com/app/apikey
- Update .env
- Restart API

### **Expo Won't Load**
```bash
npx expo start --clear
```

### **Firebase Error**
- Check Firebase config in App.js
- Verify database exists
- Check internet connection
